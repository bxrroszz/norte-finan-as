# 🧭 Norte — App de Finanças Pessoais

App web gratuito, offline e educativo de gestão financeira pessoal,
com módulo de investimentos e assistente de IA que roda no navegador.

## ✨ Funcionalidades
- 💸 Lançamentos de receitas e despesas
- 🎯 Orçamento mensal por categoria
- 🏁 Metas financeiras com cálculo automático
- 📈 Carteira de investimentos com análise educativa
- 📚 Trilhas de educação financeira
- 🤖 Assistente IA local (sem API paga)

## 🚀 Como usar
Acesse: https://SEU-USUARIO.github.io/norte/

Ou rode localmente: basta abrir `index.html` no navegador.

## 🛠️ Stack
HTML + CSS + JavaScript puro · Chart.js · localStorage
